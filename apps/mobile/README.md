# Bengali Math - Android Mobile App

This is the Android mobile app version of Bengali Math, built with Capacitor to wrap the React web app as a native Android application.

## Prerequisites

- **Node.js** (v18+)
- **Android Studio** (latest version)
- **Java JDK** (11 or higher)
- **Android SDK** (API level 22+)

## Project Structure

```
apps/mobile/
├── android/               # Native Android project (generated by Capacitor)
├── capacitor.config.json  # Capacitor configuration
├── package.json           # NPM dependencies and scripts
└── README.md              # This file
```

## Setup Instructions

### 1. Install Dependencies

```bash
cd apps/mobile
npm install
```

### 2. Build the Web App

The mobile app uses the built web assets from `ui/dist`. Build the UI first:

```bash
npm run build
# This runs: cd ../../ui && npm run build
```

### 3. Sync Capacitor

Sync the web assets with the Android project:

```bash
npm run sync
# This builds the UI and runs: npx cap sync android
```

### 4. Configure Backend URL

The app needs to connect to your backend API. You have two options:

#### Option A: Local Development (Backend on same network)

1. Find your computer's local IP address:
   - Windows: `ipconfig` (look for IPv4 Address)
   - Mac/Linux: `ifconfig` or `ip addr`

2. Update the backend URL in `ui/.env`:
   ```
   VITE_API_BASE_URL=http://YOUR_LOCAL_IP:3001/api
   ```
   Example: `VITE_API_BASE_URL=http://192.168.1.100:3001/api`

3. Ensure your backend server allows connections from the local network.

#### Option B: Production (Backend deployed to cloud)

1. Deploy your backend to a cloud service (e.g., Railway, Heroku, Google Cloud Run)
2. Update `ui/.env`:
   ```
   VITE_API_BASE_URL=https://your-backend-url.com/api
   ```

3. Rebuild and sync after changing the URL:
   ```bash
   npm run sync
   ```

### 5. Open in Android Studio

```bash
npm run open
# This runs: npx cap open android
```

This will launch Android Studio with the Android project.

### 6. Run on Device/Emulator

**Option A: From Android Studio**
1. Click the "Run" button (green play icon)
2. Select your device or emulator
3. The app will be built and installed

**Option B: From Command Line**
```bash
npm run run
# This runs: npm run sync && npx cap run android
```

## Development Workflow

### Making Changes to the UI

1. Make changes to the React app in `ui/src/`
2. Rebuild and sync:
   ```bash
   npm run sync
   ```
3. The changes will be copied to the Android project

### Making Changes to Native Android Code

1. Open Android Studio:
   ```bash
   npm run open
   ```
2. Edit native Android code in `apps/mobile/android/`
3. Build and run from Android Studio

## Build for Release

### 1. Generate Keystore (First Time Only)

```bash
keytool -genkey -v -keystore bengali-math.keystore -alias bengali-math -keyalg RSA -keysize 2048 -validity 10000
```

Save the keystore file and passwords securely!

### 2. Configure Signing

Edit `apps/mobile/android/app/build.gradle` and add:

```gradle
android {
    ...
    signingConfigs {
        release {
            storeFile file("../../bengali-math.keystore")
            storePassword "YOUR_KEYSTORE_PASSWORD"
            keyAlias "bengali-math"
            keyPassword "YOUR_KEY_PASSWORD"
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            ...
        }
    }
}
```

### 3. Build Release APK

```bash
cd android
./gradlew assembleRelease
```

The APK will be at: `android/app/build/outputs/apk/release/app-release.apk`

### 4. Build Release App Bundle (for Google Play)

```bash
cd android
./gradlew bundleRelease
```

The AAB will be at: `android/app/build/outputs/bundle/release/app-release.aab`

## Deploying to Google Play Store

### 1. Create Google Play Developer Account

- Go to [Google Play Console](https://play.google.com/console)
- Pay $25 one-time registration fee
- Complete account setup

### 2. Create App Listing

1. Click "Create app"
2. Fill in:
   - App name: "Bengali Math"
   - Default language: Bengali (or English)
   - App type: App
   - Category: Education

### 3. Complete Store Listing

Provide:
- App description (short and full)
- Screenshots (phone, tablet)
- App icon (512x512 PNG)
- Feature graphic (1024x500)
- Privacy policy URL

### 4. Upload Release Bundle

1. Go to "Release" → "Production"
2. Click "Create new release"
3. Upload the `.aab` file from step 4 above
4. Fill in release notes
5. Review and publish

### 5. Review Process

- Google reviews your app (typically 1-3 days)
- Once approved, it's live on Google Play!

## App Configuration

### Update App Name

Edit `apps/mobile/android/app/src/main/res/values/strings.xml`:

```xml
<string name="app_name">Bengali Math</string>
```

### Update App Icon

Replace icons in:
- `apps/mobile/android/app/src/main/res/mipmap-*/ic_launcher.png`

Use [Android Asset Studio](https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html) to generate icons.

### Update Package Name

If you need to change `com.bengalimath.app`:

1. Edit `capacitor.config.json` → `appId`
2. Edit `apps/mobile/android/app/build.gradle` → `applicationId`
3. Run: `npm run sync`

### Permissions

Edit `apps/mobile/android/app/src/main/AndroidManifest.xml` to add permissions like:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```

## Troubleshooting

### App can't connect to backend

- Check that `VITE_API_BASE_URL` is set correctly in `ui/.env`
- Ensure the backend URL is accessible from the device
- Check that `cleartext` is enabled in `capacitor.config.json` for HTTP URLs
- Verify backend CORS allows requests from the app

### Build errors in Android Studio

- Sync Gradle files: File → Sync Project with Gradle Files
- Invalidate caches: File → Invalidate Caches / Restart
- Check JDK version: File → Project Structure → SDK Location

### Web assets not updating

```bash
npm run sync
```

This rebuilds the UI and copies files to the Android project.
